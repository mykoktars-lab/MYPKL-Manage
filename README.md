# E-Logbook PKL Politala × PT Indofood CBP Sukses Makmur

Aplikasi pencatatan Logbook Mingguan PKL (26 September 2026 s.d 26 Maret 2027), To-Do List Harian, Catatan Rumus Lab QC, Kalkulator Rumus (FFA, AV, Kadar Air, Custom), Galeri Dokumentasi, serta Cetak & Ekspor Laporan Format Resmi Politala (Font Times New Roman).

## Cara Build APK di GitHub Actions (Lewat HP)
1. Buat repository baru di GitHub (misal: `logbook-pkl-politala`).
2. Ekstrak file ZIP ini, lalu upload file-filenya ke repository GitHub.
3. Pastikan file workflow berada di path `.github/workflows/build-apk.yml`.
4. Buka tab **Actions** di GitHub, klik workflow **Build Android APK - E-Logbook PKL Politala**, lalu unduh file **E-Logbook-PKL-Politala-APK** pada bagian **Artifacts** setelah proses build selesai (centang hijau).
